========== PAGE 7 ==========
Two’s Complement Numbers
A2:
Reverse the sign of 6 = 0110, Represent the result in two's complement form.
1. Invert all the bits
1001
2. Add 1 to the inverted result
1001+     1  = 10102
10102 = -610

========== PAGE 9 ==========
Two’s Complement Examples
A3:
What is the decimal value of the two’s complement number 10012?
1. Check the sign bit: 
if the leftmost bit is 0, the number is positive;
if the leftmost bit is 0, the number is negative.
2. Invert all the bits
0110
3. Add 1 to the inverted result
01102   +    1 = 01112
01112 = 710, so 10012 = -710
